Lab content editor

Add events, upload photographs, update people and interns, and share lab news using forms.

Changes remain a draft until you upload the downloaded update package to your GitHub repository.

Your editing workflow

1. Choose a section. 2. Add or edit an entry and save it to the draft. 3. Download updates and upload the extracted files to GitHub.

Your draft can be restored in the same browser when storage is available. A downloaded backup lets you keep it safely or move it to another computer.

A previous draft belongs to an older website version. Download it as a reference before starting a new draft.

Apply your updates

  1. Extract ASMD_Lab_Updates.zip on your computer.
  2. Open GitHub’s upload page ↗ and sign in.
  3. Drag the extracted content.js and assets folder onto that page. Upload their contents, not the ZIP itself. Preserve the assets folder structure.
  4. Review the files and select Commit changes. GitHub accepts changes only from authorised repository users.
  5. Once hosting is enabled, wait for the website deployment. For the current private draft, download the repository to review the updated pages locally.

If someone else has updated the repository since you opened this editor, download the latest website before preparing your next update to avoid overwriting their changes.

Alternatively, send the update ZIP here and ask to synchronise it.

This editor saves drafts and creates update files. It does not sign in to GitHub or publish automatically. The repository controls who can apply changes. Downloaded backups should be kept on your own computer.
